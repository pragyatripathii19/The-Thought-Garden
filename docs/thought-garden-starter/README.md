# The Thought Garden

A local-first personal space for capturing unfinished thoughts and discovering useful connections between them over time.

> Every thought has a home, even when you don't know what that home is yet.

## Product principles

1. Capture before organization. A thought can be saved without a title, tag, folder, or category.
2. Preserve the user's words. Never silently rewrite, merge, or delete original thoughts.
3. Suggest, don't dictate. Connections and collections are recommendations the user can accept or dismiss.
4. Unfinished is a valid state. Not every thought needs to become a task or project.
5. Calm over clever. The garden metaphor should guide the visual language, not make everyday use harder.
6. Local-first and transparent. The prototype stores data in this browser and offers export/import; it does not promise cloud sync.

## Prototype success criteria

The prototype is useful if a person can capture thoughts in seconds, find an old thought without remembering its exact wording, understand why a connection was suggested, and safely export their data. Validate these behaviours before expanding scope.
